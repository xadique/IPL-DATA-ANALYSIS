# 🏏 IPL Analysis Dashboard (2008 - 2025)

> ⚡ A Power BI project showcasing detailed IPL data analysis across multiple seasons. Explore player stats, team performance, and match insights through an interactive dashboard.

---

## 🔍 Overview

This repository contains a complete IPL data analysis and visualization solution using **Power BI**. The dashboard includes:

- 🏆 Champions & Runner-up analysis  
- 🧢 Orange Cap & Purple Cap holders  
- 📈 Total sixes, fours, centuries, and match stats  
- 📊 Team-wise Points Table  
- 🎯 Player performance insights  

---

## 📊 Dashboard Highlights

- Season-wise performance analysis  
- Player statistics (runs, wickets, sixes, fours)  
- Team rankings and match results  
- Interactive slicers and filters
