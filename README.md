# 🏏 IPL Analysis Dashboard (2008 - 2025)

> ⚡ A Power BI project showcasing detailed IPL data analysis across 18 seasons — from 2008 to 2025. Dive into player stats, team standings, and match highlights with a single click!

---

## 🔍 Overview

This repository contains a complete IPL data analysis and visualization solution using **Power BI**. With the latest update for **2025 IPL Season**, it features:

- 🏆 Champions & Runner-up
- 🧢 Orange Cap & Purple Cap holders
- 📈 Total sixes, fours, centuries, and match stats
- 📊 Team-wise Points Table
- 🎯 Player highlights like most sixes and fours

## 🚀 How to Use

1. Clone this repository  
2. Open the `.pbix` file in **Power BI Desktop**  
3. Ensure all `.csv` files are in the same folder  
4. Interact with visuals, filters & slicers
